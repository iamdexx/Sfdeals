# Atlanta (Fulton County) sources

Status: parcels only (absentee list). No distress layer is wired yet; every candidate found needs a small change in shared code (see Parked). Cash buyer list is empty because the parcel layer has no sale date or price.

Working, free, unattended:
- Fulton County `services1.arcgis.com/AQDHTHDrZzfsFsB5/arcgis/rest/services/Tax_Parcels_2026/FeatureServer/1` (373k parcels, 2026 digest; `ParcelID` like `14 018400070028`, `Address`, `Owner`, `OwnerAddr1`, `OwnerAddr2` = "CITY ST ZIP" in one field, `LUCode`, `ClassCode`, `ExCode` homestead exemption code, `LivUnits`, `TotAppr`, `TotAssess`, `LandAcres`). No year built, living area, situs city, zip or sale fields, so the "real house" test uses the street number only and `mail_state` is empty (out of state never fires; `mail_city` shows "Alpharetta Ga 30009" style). Single family is `LUCode = '101'` (227k). Pull is `LUCode = '101' AND OwnerAddr1 <> Address AND (ExCode IS NULL OR OwnerAddr2 NOT LIKE '% GA %')`: 48k rows in about 30 seconds. `ExCode` is kept as an extra field but not used as `occ_field`: 26k single family parcels with no exemption have the tax bill mailed to the house, and flagging them absentee would mark owner occupants who never filed. Median appraised value of the pull is about 292k; `min_value` 60000 drops 167 shells.
- Fulton also publishes `Tax_Parcels_2025`, `Tax_Parcels_2024` and `Tyler_TaxParcels` (2023 digest, 365k, same fields) on the same org, so the url only needs the year bumped each January.
- Fulton `Tolemi_Parcels/FeatureServer/0` on the City of Atlanta org `services5.arcgis.com/5RxyIIJ9boPdptdo` (190k, city parcels only) has `YrBlt`, `AreaSF`, `Homestead`, `Owner_Non_Owner`, `Housing_Type`. Not used because it covers the city only and its vintage is unclear; it is the place to get year built and living area if the "real house" test needs them.
- City of Atlanta `gis.atlantaga.gov/dpcd/rest/services/AdministrativeArea/TaxParcel/MapServer/0` (171k, city parcels with `PSTLCITY`, `PSTLSTATE`, `PSTLZIP5` split out). Not used; Fulton covers the whole county.
